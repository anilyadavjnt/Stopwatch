# ⏱️ Stopwatch iOS App

A simple, clean, and user-friendly **Stopwatch iOS application** built using **Swift and UIKit**.

This project demonstrates timer handling, UI updates, lap tracking, and basic iOS application development concepts.

## 🚀 Features

* ▶️ Start Stopwatch
* ⏸️ Pause Stopwatch
* 🔄 Reset Stopwatch
* 🏁 Lap Time Tracking
* ⏱️ Real-time timer updates
* 🎨 Clean and simple UI
* 📱 Responsive iOS interface
* ⚡ Smooth and lightweight performance

## 🛠️ Technologies Used

* **Swift**
* **UIKit**
* **Storyboard**
* **Xcode**
* **Timer**
* **Auto Layout**

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/anilyadavjnt/Stopwatch
```

2. Open the project in **Xcode**.

3. Select an iOS Simulator or connected iPhone.

4. Press:

```text
⌘ + R
```

5. Start using the Stopwatch.
